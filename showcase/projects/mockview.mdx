# MockView

## Overview

MockView is a customizable behavioral interview simulator built in 24 hours at HackRU Fall 2026 by three first-time hackers. A realistic interviewer, voiced by **ElevenLabs Text-to-Speech**, asks you questions out loud. While you answer, a live feedback panel tracks your STAR structure, speaking pace and filler words, and the interviewer reacts to what you actually said. When you finish, MockView rewrites your weakest sentence and uses ElevenLabs to play back the **ideal delivery**, so you hear how a strong answer sounds, not just read it.

## Key Features

- **Three interviewer difficulties**: Lightweight (encouraging), Moderate (professional, asks follow-ups) and Harsh (skeptical, interrupts long answers). Each persona's mannerisms map to ElevenLabs voice settings.
- **Live feedback panel**: a coaching tip, a STAR checklist, a pace bar and a filler-word counter, updating while you talk.
- **Feedback report**: your transcript with clickable red-flag and filler pills that reveal the "interviewer's inner monologue", plus a GitHub-style diff that rewrites your weakest sentence.
- **Hear Ideal Delivery**: plays the rewritten sentence with ElevenLabs `eleven_v4`, next to your original for contrast.
- **Reactive interviewer**: responds to what you actually said after each answer, asks "Sorry, what was that?" when it hears nothing, and stops after repeated silence.
- **Works in any modern browser**: where built-in speech recognition is blocked (Brave) or missing (Firefox), answers stream to ElevenLabs real-time Scribe (`scribe_v2_realtime`), so words appear as you speak.
- **Accessibility and languages**: larger text, high contrast, reduced motion, interviewer captions and keyboard shortcuts. Every question can be shown and read aloud in Spanish, Chinese, Hindi, Korean or Portuguese with ElevenLabs Eleven v4.
- **Beginner level**: basic warm-up questions with lighter grading, alongside internship, new-grad and experienced levels across 14 fields.
- **Flexible sessions**: a fixed number of questions, a timed session, or Endless Mode, with optional questions generated from your resume.
- **Accounts and settings**: email sign-in that syncs your setup across devices; theme, voice model and speed, and interview options.

## How It Works

- **ElevenLabs TTS** (`/v1/text-to-speech/{voice_id}`) voices every interviewer line. Each persona's mannerisms map straight onto ElevenLabs voice settings: pace → `speed`, expressiveness → lower `stability` plus higher `style`. `<break time="0.6s"/>` tags add natural beats before each question. Users choose between `eleven_v4` (most realistic) and `eleven_flash_v2_5` (lowest latency).
- The next question's audio is **prefetched** while the current one plays, so there is no dead air between questions.
- A tiny server proxy (a Vite middleware locally, a Vercel function in production) keeps the API key off the client.
- The interviewer's audio runs through a Web Audio `AnalyserNode` that drives the live waveform visualizer.
- Speech input uses the browser's Web Speech API for zero-latency transcripts, and falls back to **ElevenLabs Scribe** (`/v1/speech-to-text`, `scribe_v1`) with pause-to-pause clips when that API is blocked or missing. A local rules engine (regex dictionaries plus STAR heuristics) scores content instantly. A pitch and loudness analyser on the mic stream (autocorrelation pitch detection with an adaptive noise floor) scores vocal delivery.

## Technologies Used

- ElevenLabs API: Text-to-Speech (Eleven v4, Flash v2.5, voice settings, break tags) and Speech-to-Text (real-time Scribe v2, batch Scribe as fallback)
- React 18 + Vite
- Web Speech API, Web Audio API
- Vercel serverless functions

## Getting Started

```bash
git clone https://github.com/sttstevenyao/mockview.git
cd mockview
npm install
cp .env.example .env   # add your ELEVENLABS_API_KEY
npm run dev            # open http://localhost:5173
```
